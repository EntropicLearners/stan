Stan - Learning assistant for Thermodynamics
============================================

Stan is a learning assistant system for chemical engineering thermodynamics. 
The name is an homage to Stanley Sandler whose work in the area and 
pedagogical contributions inspire us.

Stan consists of the following key elements

* LLM powered learning assistant
* Datasets used in the class and for training the LLM powered learning assistant.
* The `stan` python library with codes, routines, and convenience functions that area
  provided with the textbook and used in the class. It also includes routines to 
  interact programmatically with the models and data underlying the learning 
  assistant.
